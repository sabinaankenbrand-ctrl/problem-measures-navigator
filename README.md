# Problem–Measure Navigator

Interactive view of the DANUBE4all (D4A) / DSQ2 problem–measure matrix (WP7).

- Left: 56 problems by problem category
- Middle: measure tree (6 categories, 18 groups, 95 measures)
- Right: measures for the current selection
- Switch between D4A (95 measures) and DSQ2 (77 measures)

## Files
- `index.html` – the page
- `data.js` – catalogue, matrix links and group icons (generated from the grouping file and matrix fin1)

To update the data, replace `data.js` with a newly generated one.
